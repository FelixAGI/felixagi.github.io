    The mathematics

    From a coordinate to an exact byte.

    FX1 is a compact description of a deterministic read-only volume. The geometry creates addressable output; literal bytes and corrections preserve files exactly where a rule alone cannot.

    Package

    FX1 | base64url(FXB1) | crc32(FXB1)

    FXB1 holds the file tree, geometry, VM program, and any required literal bytes.

    Address space

    N = q × ∏ nj4 × 1624 = 298 byte addresses

    q is the channel count; each axis contributes its own number of states.

    Coordinates

    c = A mod q;   p = ⌊A / q⌋xj = p mod nj;   p = ⌊p / nj⌋

    Iterating over the axes locates the requested channel and position without enumerating earlier bytes.

    Rotation

    θ(s, r) = 2πs / rb = (shigh << 4) | slow

    Angular states are a representation of byte values, not extra information inserted into a QR.

    Exact file compiler

    cell(y) = ⌊y / 256⌋F(y) = Δ(y) if present; otherwise Mcell(y)(y mod 256)

    Each cell can use a repeat, line, curve, XOR ramp, orbit, or exact literal. Matching models share branches.
